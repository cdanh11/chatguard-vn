# Huấn luyện

Chưa có pipeline.

Lộ trình: thiết kế nhãn và bộ đánh giá → đo mô hình nền → thử SFT/QLoRA → chọn cấu hình bằng validation → đánh giá trên test đã khóa.

Công cụ dự kiến: Transformers, Datasets, TRL, PEFT, bitsandbytes. Chốt phiên bản sau khi thử với phần cứng thực tế. Không commit checkpoints hoặc weights.
